# Public demonstration

[Watch the complete BEFORE / AFTER video](../assets/demo/quokkai-lab-fix-lip-sync.mp4).

The author selected this presentation edit for publication. The repository includes
the complete comparison and a preview extracted from it. Raw production input
images, voice recordings, per-scene workflows and private manifests are not bundled.

To make your own reproducible baseline/fix pair, follow [the protocol](../DEMO.md).
Use the same inputs, prompts, seeds, models and generation settings in both arms.
The baseline is the equivalent pipeline without the conditioning treatment,
not an official upstream workflow. Results vary; the selected examples do not
establish a universal gain.
